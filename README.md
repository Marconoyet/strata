# STRATA Dental Clinic — Next.js

Bilingual (Arabic/English) luxury dental clinic website.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + Framer Motion + Lucide React
- Full RTL/LTR language switching

## Get Started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Language

Click **EN** / **AR** in the navbar to toggle language.
